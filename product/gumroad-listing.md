## Description

workflow-kit gives a solo developer or small team a ready-made, opinionated
workflow for AI-assisted coding. Drop the templates, slash commands, subagent
personas, and a universal verifier (`wf-verify`) into your config and start
shipping verified changes the same day.

**What's inside (free core):**

- `templates/` — SPEC.md, PLAN.md, ACCEPTANCE.md
- `bin/wf-verify` — universal verifier (Go, Bun/Node, Rust, Deno, Ruby, TS,
  Make, Python); falls back to project `verify.sh`
- `commands/` — /spec /plan /verify /test /review /ship /flow /status /doctor
- `agents/` — implementer, tester, docs-writer, code-reviewer, go-programmer,
  software-architect, Oscar
- `docs/PLAYBOOK.md` — better flow + command reference
- `install.sh`, `selftest.sh`, GitHub Actions `verify.yml`
