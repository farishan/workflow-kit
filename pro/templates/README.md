# Pro templates

Premium template variants for Pro/Team tiers:
- `landing.html` — polished landing-page template (static HTML + Tailwind, single file, no build).
- `SPEC-PRO.md` — extended spec with threat model + perf budgets.
- `PLAN-PRO.md` — plan with risk register + rollback.
- `ACCEPTANCE-PRO.md` — acceptance with SLA checks.

These ship in the Pro pack zip. Use them in place of the free `templates/`
versions when the change is security-sensitive, performance-critical, or
cross-cutting.
