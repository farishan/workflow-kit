Features

Everything you need to run the better flow end to end.

Universal verifier

Commands

Slash commands for the full loop.

Agents

Specialized subagents: implementer, tester, docs-writer, code-reviewer, go-programmer, software-architect.

Templates

SPEC.md, PLAN.md, ACCEPTANCE.md — scaffolded by /spec for v0 minimal scope.

Examples

10 example projects across Go, Bun, Rust, Python, Deno, PHP, TS, Make and Ruby — all pass wf-verify.

Selftest

selftest.sh runs wf-verify across demos and examples to catch regressions before you ship.

How it works

Four steps from idea to shipped change.

1

Spec

Run /spec to scaffold SPEC.md, PLAN.md and ACCEPTANCE.md for a v0-minimal scope.

2

Implement

Spawn isolated workers and write code against the plan, one focused change at a time.

3

Verify

Run wf-verify (or /verify) to build, typecheck, test and lint for your stack.

4

Ship

Review with /review, fix, then /ship. Log status and memory.

Install

One command. See docs/INSTALL.md for manual steps.

./install.sh

Installs commands, agents and templates into ~/.config/opencode and wf-verify into ~/.local/bin. Ensure ~/.local/bin is on your PATH.
